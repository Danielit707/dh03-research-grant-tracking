## Status conventions

- **Proposed**: architectural recommendation from the draft, not yet accepted or implemented.
- **Open**: requires stakeholder confirmation or evidence.
- **NOT EXECUTED**: no test result is claimed.

The root [README.md](../../README.md) is the submission manifest and top-level navigation.
